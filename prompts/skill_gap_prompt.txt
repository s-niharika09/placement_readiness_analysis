Definitions

matched_skills

Return every skill that appears in both the Resume and the Job Description.

missing_skills

Return every required skill from the Job Description that is absent from the Resume.

critical_missing_skills

Return only the mandatory missing skills that are essential for performing the role successfully.

optional_missing_skills

Return only the preferred or nice-to-have skills that are missing.

skills_to_learn_first

Return the TOP FIVE skills the candidate should learn first.

Prioritize using this order:

1. Critical technical skills
2. Core programming languages
3. Frameworks and libraries
4. Cloud technologies
5. Development tools

The skills should be ordered from highest priority to lowest priority.

Rules
